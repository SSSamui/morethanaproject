# Puppy Pomodoro for iPhone — all versions

Every change to the iPhone version is saved here as its own zip. Old versions are never overwritten.

Each zip unzips to its own folder (for example `puppy-pomodoro-iphone-v1.0.0`), so different versions can sit side by side on your Mac. To install one, open its `PuppyPomodoro.xcodeproj` in Xcode and follow the steps in that folder's `README.md`.

To download a single version, click its zip below, then **Download raw file** (the ⬇ button).
