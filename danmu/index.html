📱 Open videos straight from the YouTube app

Android (Pixel, Samsung…):

  1. In Chrome, tap ⋮ → Install app (or Add to Home screen → Install). Or tap:
  2. In the YouTube app: Share → VideoIQ. The video opens here with danmu.

iPhone:

  1. Open the Shortcuts app → + (new shortcut).
  2. Tap the ⓘ (or shortcut name) → turn on Show in Share Sheet, set it to receive URLs and Text.
  3. Add the action URL and type: then insert Shortcut Input right after =.
  4. Add the action Open URLs. Name the shortcut VideoIQ.
  5. In the YouTube app: Share → More → VideoIQ. The video opens here with danmu.

Tip: in Safari tap Share → Add to Home Screen to use this page like an app.
